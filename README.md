# POS Multi-Company Project

Modern Point of Sale system with a Multi-Company architecture.

## Architecture

- **Frontend**: Next.js (App Router, Tailwind CSS, Zustand, Framer Motion)
- **Backend**: Golang (Fiber Framework)
- **Database**: PostgreeSQL

## Directory Structure

- `frontend/`: Next.js web application.
- `backend/`: Go API server.

## Getting Started

### Frontend

```bash
cd frontend
pnpm install
pnpm run dev
```

### Backend

```bash
cd backend
go run cmd/api/main.go
```

## Features

- [x] Premium Landing Page
- [x] Modular UI Components
- [x] Complex Checkout Flow
- [x] Dashboard Layout
- [x] State Management (Zustand)
- [x] Go API Boilerplate
